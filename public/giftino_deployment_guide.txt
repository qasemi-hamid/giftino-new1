================================================================================
          راهنمای جامع و صفر تا صد راه‌اندازی، اتصال به گیت‌هاب و سرور لینوکس (گیفتی‌نو)
================================================================================

این دفترچه راهنما تمامی دستورات لازم از لحظه اتصال با IP به VPS لینوکس،
تنظیمات Nginx و SSL، اتصال مستقیم به ریپازیتوری GitHub بدون نیاز به دانلود زیپ،
و بیلد و مدیریت پروسه‌ها با PM2 را با توضیحات کامل پوشش می‌دهد.

--------------------------------------------------------------------------------
بخش اول: اتصال اولیه به سرور و نصب پیش‌نیازها
--------------------------------------------------------------------------------

۱. اتصال به سرور لینوکس با SSH:
   ssh root@YOUR_SERVER_IP
   توضیح: با این دستور از طریق ترمینال کامپیوتر خود به سرور لینوکس متصل می‌شوید.

۲. به‌روزرسانی مخازن لینوکس:
   sudo apt update && sudo apt upgrade -y
   توضیح: پکیج‌های سیستم‌عامل لینوکس را آپدیت می‌کند تا همه ابزارها در آخرین نسخه باشند.

۳. نصب Node.js (نسخه ۲۰ پایدار):
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs
   توضیح: محیط اجرای نود و مدیریت پکیج npm را نصب می‌کند.

۴. نصب ابزارهای ضروری (Git, Nginx, Unzip):
   sudo apt install -y git nginx unzip
   توضیح: گیت برای دریافت کدها، Nginx برای وب‌سرور و مدیریت SSL، و Unzip برای استخراج فایل‌ها.

۵. نصب PM2 (مدیر پروسه نود):
   sudo npm install -g pm2
   توضیح: برای زنده نگه‌داشتن برنامه در پس‌زمینه سرور و استارت خودکار هنگام ریبوت.


--------------------------------------------------------------------------------
بخش دوم: اتصال مستقیم پوشه پروژه به GitHub (جایگزین دانلود زیپ)
--------------------------------------------------------------------------------

۱. ورود به پوشه پروژه در سرور:
   cd /home/giftino/giftino-new-main
   توضیح: وارد پوشه‌ای می‌شوید که قرار است فایل‌های سورس پروژه در آن قرار گیرد.

۲. ساخت مخزن گیت محلی در پوشه:
   git init
   توضیح: این پوشه را به یک مخزن Git تبدیل می‌کند.

۳. اتصال پوشه به ریپازیتوری گیت‌هاب شما:
   git remote add origin https://github.com/qasemi-hamid/giftino-new.git
   توضیح: لینک ریپازیتوری گیت‌هاب شما را به عنوان آدرس اصلی (origin) تنظیم می‌کند.

۴. دریافت تمام اطلاعات و برنچ‌ها از گیت‌هاب:
   git fetch origin
   توضیح: تمام کدها و کامیت‌های جدید را از گیت‌هاب دانلود می‌کند (بدون اعمال مستقیم).

۵. همگام‌سازی و جایگزینی کامل فایل‌ها با آخرین نسخه گیت‌هاب (دستور طلایی):
   git reset --hard origin/main
   توضیح: این دستور دقیقا پوشه سرور شما را با آخرین کد موجود روی شاخه main گیت‌هاب یکسان می‌کند و نیازی به دانلود فایل zip نیست.


--------------------------------------------------------------------------------
بخش سوم: بیلد و اجرای برنامه
--------------------------------------------------------------------------------

۱. نصب وابستگی‌های پروژه:
   npm install
   توضیح: تمام پکیج‌های ذکر شده در package.json را نصب می‌کند.

۲. ساخت نسخه تولید (Production Build):
   npm run build
   توضیح: کدهای تایپ‌اسکریپت و ری‌اکت را کمپایل کرده و فایل خروجی dist/server.cjs را می‌سازد.

۳. اجرای برنامه با PM2:
   pm2 start dist/server.cjs --name "giftino"
   توضیح: برنامه را روی سرور به صورت ۲۴ ساعته اجرا می‌کند.

۴. ذخیره وضعیت PM2 جهت اجرا بعد از ریبوت سرور:
   pm2 save
   pm2 startup


--------------------------------------------------------------------------------
بخش چهارم: تنظیمات SSL و Nginx
--------------------------------------------------------------------------------

۱. بررسی صحت کانفیگ Nginx:
   sudo nginx -t
   توضیح: چک می‌کند که آدرس‌ها و فایل‌های گواهی SSL در فایل nginx.conf درست تنظیم شده باشند.

۲. اعمال تغییرات Nginx:
   sudo systemctl reload nginx
   توضیح: بدون قطعی سرور، تنظیمات جدید وب‌سرور را فعال می‌کند.

۳. مشاهده کلید خصوصی SSL (در صورت نیاز به بررسی):
   sudo cat /etc/ssl/giftino/private.key


--------------------------------------------------------------------------------
بخش پنجم: دستور ۱-خطی برای آپدیت‌های بعدی پروژه (کارهای روزمره)
--------------------------------------------------------------------------------

هر زمان تغییر جدیدی روی گیت‌هاب ایجاد کردید، فقط کافیست این یک خط دستور را در پوشه پروژه بزنید:

cd /home/giftino/giftino-new-main && git fetch origin && git reset --hard origin/main && npm install && npm run build && pm2 restart giftino

توضیح دستور فوق:
۱. وارد پوشه پروژه می‌شود.
۲. کدهای جدید را از گیت‌هاب می‌گیرد.
۳. پوشه را با آخرین کد main همگام می‌کند.
۴. پکیج‌های جدید احتمالی را نصب می‌کند.
۵. پروژه را بیلد مجدد می‌کند.
۶. برنامه را بدون قطعی ری‌استارت می‌کند.


--------------------------------------------------------------------------------
جدول خلاصه دستورات کاربردی مدیریت سرور:
--------------------------------------------------------------------------------
• مشاهده وضعیت برنامه:       pm2 status
• مشاهده لوگ‌های زنده خطایابی:  pm2 logs giftino
• ری‌استارت برنامه:           pm2 restart giftino
• وضعیت وب‌سرور ان‌جین‌ایکس:     sudo systemctl status nginx
• چک کردن فضای دیسک سرور:     df -h
• چک کردن رم اشغالی:          free -m
